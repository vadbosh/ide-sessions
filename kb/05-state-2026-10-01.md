# 0.10.0 — agent-history, скилл history и /history теперь здесь

## Что сделано

- `bin/agent-history`, `skills/history/SKILL.md`, `commands/history.md` перенесены в репозиторий. До этого `~/.local/bin/agent-history` (2026-07-03) не ставил ни один репозиторий, а скилл и команда жили только в приватном каноне `~/ai-config-source`.
- `install.sh` ставит скилл во все найденные ассистенты, `/history` — в Claude Code и opencode (у Codex нет пользовательских команд). Codex находит скилл в `~/.codex/skills` сам: `[[skills.config]]` в `config.toml` только выключает скиллы, регистрировать не нужно.
- Бэкап заменённого файла скилла или команды — в `~/.local/state/ide-sessions/backups/`, не рядом: рядом он загрузился бы вторым скиллом.

## Что открыто

- Канон `~/ai-config-source` всё ещё держит свои копии `skills/history` и `commands/history.md`. Передача владения (убрать оттуда, внести в `BUNDLE`) — работа в каноне, не здесь.
- `agent-history` пишет полный вывод в `/tmp` с правами 600 и удаляет файлы старше часа: обещание «ничего не теряется» держится час.

## Чем проверить состояние

```bash
bash tests/test_sessions.sh                     # хорошо = N passed, 0 failed
for f in agent-history; do cmp -s ~/.local/bin/$f bin/$f && echo "same $f"; done
cmp -s ~/.claude/skills/history/SKILL.md skills/history/SKILL.md && echo "same skill"
```
